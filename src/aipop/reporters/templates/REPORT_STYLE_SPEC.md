# AIPOP Report Style Spec
# ScoutSuite axioms, modern execution

## What to steal from ScoutSuite
- Structured finding cards with consistent sections
- Every finding has: severity, description, evidence, impact, remediation
- Framework references as first-class data, not afterthought
- Sortable/filterable findings table
- Evidence is inline, not in a separate appendix

## What to KILL from ScoutSuite
- The 2018 Bootstrap aesthetic. We're not building a dashboard from 2018.
- Tiny gray text on white. Unreadable.
- Cluttered nav bars and sidebars. The report is a DOCUMENT, not a webapp.
- Color scheme looks like AWS console threw up.

## Our aesthetic
- Clean, modern, dark navy headers (#1a1a2e or similar)
- White content areas with generous whitespace
- System font stack (no Google Fonts, loads instantly)
- Severity badges that POP:
  - Critical: deep red (#dc2626) white text
  - High: red (#ef4444) white text
  - Medium: amber (#f59e0b) dark text
  - Low: blue (#3b82f6) white text
  - Info: gray (#6b7280) white text
- Finding cards with left-border severity stripe (like GitHub PR labels)
- Monospace for evidence/code blocks (JetBrains Mono stack → Fira Code → monospace)
- Subtle shadows on cards, not flat
- Generous padding (the CISO reads this on an iPad)

## Finding card structure
Each finding is a card with a colored left border matching severity:

```
┃ CRITICAL                                    AI-2026-001
┃
┃ System Prompt Disclosure via Output Format Manipulation
┃ ─────────────────────────────────────────────────────────
┃ Target: http://target:8003/api/generate
┃ CVSS 3.1: 8.6 (High)  •  Confidence: CERTAIN
┃
┃ DESCRIPTION
┃ The target system disclosed its complete system prompt...
┃
┃ ▶ EVIDENCE (click to expand)
┃   Request: POST /api/generate {...}
┃   Response: {"system_prompt": "You are MailMind..."}
┃
┃ IMPACT
┃ • API key prefix enables targeted credential attacks
┃ • AWS Account ID enables cloud reconnaissance
┃
┃ FRAMEWORK REFERENCES
┃ OWASP LLM:     LLM01 — Prompt Injection
┃ MITRE ATLAS:    AML.T0051
┃ CWE:            CWE-200
┃ NIST AI RMF:    MEASURE 2.6
┃
┃ REMEDIATION                                   IMMEDIATE
┃ 1. Implement output structure enforcement...
┃ 2. Remove sensitive values from system prompt...
┃
┃ VERIFICATION
┃ aipop suite run --test cc_output_format_hijack
```

## Print CSS
- White background everywhere
- All details/summary expanded (no collapsed sections)
- Page break before each finding card
- Page break before each major section (exec summary, findings, compliance, methodology)
- No shadows (they print as gray blocks)
- Severity badges use borders instead of backgrounds for ink saving
- Footer with "Generated by AIPOP v0.8.0 • Confidential" on every page

## Language
- Formal pentest report language throughout
- "The target system disclosed..." not "the chatbot leaked..."
- "An unauthenticated attacker can extract..." not "someone could get..."
- "This finding is remotely exploitable without authentication"
- Active voice for impact, passive for description
- Numbers are specific: "API key prefix apex_prod_sk_" not "API credentials"
